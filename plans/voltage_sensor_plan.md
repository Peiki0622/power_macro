# 基于 SMIC40LL 标准单元的电压跌落传感器计划

## 1. 目标

设计一个部署在芯粒 A 本地电源岛上的全数字电压跌落传感器，用于将局部 `VDD_A - VSS_A` 的变化转换为数字时间序列，供后续一维 TCN 判断 `Safe / Warning / Critical` 状态。

该传感器应满足：

- 直接连接芯粒 A 本地电源节点，而不是理想电源源端；
- 使用 SMIC40LL 标准单元库，不自行设计晶体管级单元；
- 可在 SPICE 中完成电压灵敏度与瞬态响应前仿；
- 后续可通过结构化 Verilog、综合和 Innovus 完成版图实现；
- 传感器自身功耗不能显著加剧芯粒 A 的电压跌落。

---

## 2. 总体结构

```text
START
  |
  v
非反相延迟单元 0 -> 非反相延迟单元 1 -> ... -> 非反相延迟单元 N-1
       |                  |                          |
     tap[0]             tap[1]                   tap[N-1]
       \___________________固定时刻采样________________/
                              |
                         温度计码
                              |
                    纠错 + 二进制编码
                              |
                         droop_code
                              |
                           1D-TCN
```

每个非反相延迟单元由两个最小驱动反相器组成：

```text
IN -> INVX1 -> INVX1 -> OUT
```

采用两个反相器的原因是保证各级 tap 极性一致，从而在固定采样时刻形成近似温度计码。

---

## 3. 标准单元与库文件要求

需要确认 SMIC40LL 标准单元库中包含：

- 标准单元 SPICE/CDL 子电路网表；
- 工艺模型及 TT/SS/FF 角；
- 标准单元 Verilog 功能模型；
- Liberty `.lib`；
- LEF/GDS 物理视图；
- 可用的最小驱动反相器、缓冲器和 D 触发器。

优先使用：

- `INVX1` 或库中等效的最小驱动反相器；
- 若库中有合适的最小缓冲器，也可直接比较 `BUFX1` 与双反相器结构；
- 后续采样寄存器使用库中的标准 DFF。

注意：仅使用 Liberty 文件不足以完成瞬态电源跌落前仿，SPICE 前仿必须调用标准单元的 SPICE/CDL 电路视图。

---

## 4. 第一阶段：延迟链前仿

### 4.1 候选链长

先比较三种配置：

| 配置 | 非反相延迟单元数 | 反相器总数 |
|---|---:|---:|
| Small | 16 | 32 |
| Medium | 32 | 64 |
| Large | 64 | 128 |

优先从 32 个非反相延迟单元开始。

### 4.2 电源连接

所有延迟单元显式连接：

```text
VDD_SENSOR = VDD_A
VSS_SENSOR = VSS_A
```

其中 `VDD_A` 和 `VSS_A` 为芯粒 A 经过共享 RLC 网络后的本地电源与地节点。

### 4.3 恒定供电扫描

对传感器电源进行离散扫描：

```text
Vnom,
Vnom - 10 mV,
Vnom - 20 mV,
...,
Vnom - 150 mV
```

每个电压点测量：

- 单级传播延迟；
- 整条链传播延迟；
- 固定采样时刻的传播级数 `K`；
- 延迟链平均功耗与峰值电流。

得到标定关系：

```text
VDD_A -> K_sense
```

链长和采样时刻的选择标准：

1. 正常电压下，START 边沿传播到链中部；
2. 首次时序违例对应的电压附近，传播码至少变化 2～3 级；
3. 最大电压跌落时仍处于可解析范围；
4. 延迟链自身不会产生不可接受的附加电压跌落。

---

## 5. 第二阶段：人工瞬态跌落实验

在尚未接入完整双芯粒系统前，使用 PWL 电源测试：

- 跌落幅度：10、20、40、80、140 mV；
- 不同下降时间；
- 不同持续时间；
- 不同恢复速度。

需要记录：

- `VDD_A(t) - VSS_A(t)`；
- 各级 tap 波形；
- 固定采样时刻的传播码；
- 传感器响应延迟；
- 最小可检测跌落幅度；
- 对短脉冲跌落的漏检情况。

前仿初期可以不实例化真实 DFF，直接保存所有 tap 的模拟波形，并用脚本在采样时刻完成逻辑判决。

判决阈值使用局部动态中点：

```text
Vth_sample = (VDD_A(Tsample) + VSS_A(Tsample)) / 2
```

## 6. 第三阶段：接入现有双芯粒共享 RLC 平台

现有平台扩展为：

```text
共享电源源
   |
共享封装/中介层 RLC
   |
   +-- 芯粒 A 本地电源节点
   |      +-- 芯粒 A 功能负载
   |      +-- 功耗随机化 macro
   |      +-- 标准单元延迟链传感器
   |
   +-- 芯粒 B 本地电源节点
          +-- RO-bank 攻击负载
```

对不同 RO-bank 数量进行瞬态仿真，建立：

```text
RO-bank 数量
    -> 芯粒 A 本地电压
    -> 传感器传播码
    -> 最差路径裕量
    -> 违例路径数量
```

重点测试首次出现路径违例附近的 RO-bank 数量，而不是只测试大规模、容易检测的攻击。

建议输出 CSV：

```text
time,
ro_enable,
ro_bank_count,
vdd_a,
vss_a,
local_voltage,
propagation_code,
min_slack,
violated_path_count
```

该数据将直接作为后续 TCN 的训练与测试数据来源。

---

## 7. 第四阶段：加入真实采样与数字后端

延迟链参数确定后，再加入：

- 标准单元 DFF 采样阵列；
- 温度计码气泡纠错；
- 温度计码转二进制；
- 启动校准逻辑；
- 数据窗口缓存；
- TCN 输入接口。

第一版可以采用单链启动校准：

```text
D[k] = K0 - Ksense[k]
```

其中 `K0` 为上电后、无攻击条件下的基线传播码。

TCN 建议输入：

```text
x1[k] = D[k]
x2[k] = D[k] - D[k-1]
x3[k] = 短窗口内最差传播码
```

后续如需增强 PVT 鲁棒性，再增加参考延迟链。

---

## 8. 第五阶段：结构化 Verilog 与版图实现

使用结构化 Verilog 描述延迟链连接，不使用固定 `#delay` 行为模型。

流程：

```text
结构化 Verilog
  -> 综合
  -> 保持标准单元实例和链结构
  -> Innovus 布局布线
  -> 连接芯粒 A 本地 VDD/VSS
  -> 提取 RC 寄生
  -> SPICE 后仿
```

需要添加：

- `dont_touch`；
- 禁止重构或删除延迟链；
- 保持单元级联顺序；
- 单独 placement region；
- 延迟链与采样寄存器靠近放置；
- 随机功耗负载与传感器保持物理间隔。

## 9. 必做实验

### 9.1 灵敏度

- 输出码—电压曲线；
- 最小可检测电压变化；
- 在首次违例电压附近的码间距；
- 单调性与非线性。

### 9.2 动态响应

- 不同跌落幅度；
- 不同跌落宽度；
- 不同边沿速度；
- 响应时间与恢复时间。

### 9.3 自扰动

比较传感器关闭和开启时：

- 芯粒 A 最低电压；
- 总电流；
- 最差路径裕量；
- 违例路径数量。

### 9.4 PVT

初期只做：

- TT、SS、FF；
- 室温和高温；
- 少量供电偏差。

### 9.5 与攻击联合验证

同一时间轴展示：

1. 芯粒 B 的 RO 使能；
2. RO 攻击电流；
3. 芯粒 A 本地电压；
4. 传感器传播码；
5. TCN 状态；
6. 首条路径违例时刻。

目标：

```text
T_TCN_alarm < T_first_violation
```

---

## 10. 验收标准

传感器达到以下条件后，可以进入 TCN 与防御控制阶段：

- 在首次违例电压附近至少产生 2～3 码变化；
- 对目标最小攻击强度具有稳定响应；
- 响应时间早于首条路径违例；
- 自身附加电流不会显著改变贡献一的原始攻击边界；
- TT/SS/FF 下经过基线校准后保持可分辨；
- 能稳定输出供 TCN 使用的数字时间序列。

## 12. 当前最优先任务

1. 确认 SMIC40LL 库中最小驱动反相器的 SPICE/CDL 子电路名和电源引脚顺序；
2. 自动生成 16/32/64 级双反相器延迟链 SPICE 网表；
3. 完成恒定供电扫描；
4. 确定最佳链长和固定采样时刻；
5. 接入现有共享 RLC 双芯粒模型；
6. 输出传播码与 RO-bank、局部电压、最差路径裕量之间的关系。
