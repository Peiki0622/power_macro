## Debug Process Summary

### Issues Encountered and Resolved

1. **Port Width Mismatch (Pre-simulation)**
   - **Issue:** `medium_code` and `fsm_state` port widths didn't match submodule definitions
   - **Resolution:** Corrected RTL port widths from [3:0] to [4:0] and [4:0] respectively
   - **Impact:** Prevented synthesis errors, all modules synthesized correctly

2. **Timing Violations in Initial Simulation**
   - **Issue:** 1ns clock period caused extensive timing violations in standard cell models
   - **Resolution:** Relaxed clock to 10ns (100 MHz) for functional verification
   - **Impact:** Eliminated timing check warnings, cleaner simulation output

3. **X-State Propagation with Full Timing**
   - **Issue:** With full timing enabled, signals entered X-state during operation (~3us into simulation)
   - **Root Cause:** Timing violations causing metastability in zero-delay functional model
   - **Resolution:** Enabled `+delay_mode_zero` and `+notimingcheck` for pure functional verification
   - **Impact:** Clean functional simulation, all tests pass
   - **Note:** Timing verification deferred to Phase 8B with proper SDF back-annotation

4. **Sensor Model Port Mismatch**
   - **Issue:** Testbench initially used incorrect port connections for sensor model
   - **Resolution:** Corrected instantiation to match actual behavioral model interface
   - **Impact:** Sensor model correctly loaded scenarios and responded to controller
