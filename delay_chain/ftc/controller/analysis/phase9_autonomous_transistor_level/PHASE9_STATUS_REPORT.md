## Phase 9 Objectives

From the plan document:

> Replace the open-loop PWL controller stimulus with the real synthesized standard-cell controller and prove autonomous startup calibration of the frozen transistor-level sensor.

### Success Criteria

All three voltage scenarios must pass:
1. **0.80V:** Autonomous calibration converges to M7/F6
2. **0.95V:** Autonomous calibration converges to M4/F6
3. **1.10V:** Autonomous calibration converges to M2/F9

### Testbench Constraints

**ALLOWED external inputs:**
- VDD / VSS
- `ctrl_por_n` (power-on reset)
- `cal_start` (calibration trigger)
- `cal_clk` (external clock)

**FORBIDDEN direct drives:**
- Medium/fine configuration thermometers
- Sensor DFF reset
- Sensor S_CLK
- Internal FSM state
- Q sample strobes

All sensor control must be generated by the synthesized controller autonomously.

## Critical Challenge: Mixed-Signal Simulation

Phase 9 requires simulating:
- **Digital domain:** Gate-level standard cells (~500 cells, synchronous logic)
- **Analog domain:** Transistor-level sensor (hundreds of transistors, delay chains)

### Integration Approaches Evaluated

#### Approach A: Full SPICE Simulation ⭐ (Most Accurate)

**Method:**
- Convert gate-level Verilog netlist to SPICE (.cdl/.sp format)
- Use standard cell SPICE models from SMIC library
- Include transistor-level sensor
- Run full HSPICE transient simulation

**Pros:**
- ✓ Most accurate representation
- ✓ No abstraction or interface assumptions
- ✓ Verifies all analog/digital interactions
- ✓ Production-quality verification

**Cons:**
- ✗ **Extremely slow:** 50-100+ CPU hours per scenario
- ✗ Requires Verilog-to-SPICE netlist conversion
- ✗ Requires standard cell SPICE library (not just .lib)
- ✗ Memory intensive (~10+ GB RAM)

**Feasibility:** POSSIBLE but resource-intensive

**Required artifacts:**
1. Standard cell SPICE library (.sp subcircuits)
2. Verilog-to-SPICE netlist converter (or manual conversion)
3. Compute resources: 3 scenarios × 100 hours = 300 CPU hours

---

#### Approach B: Mixed-Signal Co-Simulation

**Method:**
- Digital controller in Verilog (VCS/NC-Verilog)
- Analog sensor in SPICE (HSPICE)
- Interface via Verilog-AMS connect modules or similar

**Pros:**
- ✓ Faster than full SPICE (10-50× speedup)
- ✓ Native Verilog for digital (no conversion)
- ✓ Accurate analog domain

**Cons:**
- ✗ Requires specialized tools (AMS Designer, VCS-AMS, Virtuoso-AMS)
- ✗ Interface abstraction can introduce errors
- ✗ Tool setup complexity
- ✗ License/access requirements

**Feasibility:** POSSIBLE if tools available

---

#### Approach C: Behavioral Digital Controller ⭐ (Pragmatic)

**Method:**
- Replace gate-level netlist with cycle-accurate behavioral model
- Implement controller FSM in HSPICE behavioral elements or Verilog-A
- Preserve exact timing from Phase 8B SDF simulation
- Interface with transistor-level sensor
- Verify autonomous calibration concept

**Pros:**
- ✓ Tractable simulation time (1-5 hours per scenario)
- ✓ Standard HSPICE flow (no special tools)
- ✓ Verifies digital/analog interface and sensor response
- ✓ Preserves protocol timing from Phase 8B
- ✓ Sufficient for Phase 9 GO decision

**Cons:**
- ✗ Not true gate-level verification
- ✗ Requires implementing behavioral model matching RTL
- ✗ Abstracts standard cell delays (uses timing tables)

**Feasibility:** PRACTICAL and RECOMMENDED for initial Phase 9

**Implementation Plan:**
1. Create HSPICE behavioral model of controller FSM
2. Encode state machine from `ftc_cal_controller_fsm.sv`
3. Implement timing delays from Phase 8B SDF measurements
4. Generate protocol-correct control signals (thermometer, S_CLK, dff_reset)
5. Interface with transistor-level sensor
6. Verify autonomous calibration

## Recommendation: Hybrid Verification Strategy

**For Phase 9 Initial GO Decision:**
- Use **Approach C** (Behavioral Digital Controller)
- Verify all three scenarios (0.80V, 0.95V, 1.10V)
- Demonstrate autonomous calibration concept
- Validate digital/analog interface
- Simulation time: ~10-15 hours total

**Rationale:**
- Proves autonomous calibration feasibility
- Verifies sensor response to synthesized controller protocol
- Sufficient confidence for controller design GO
- Tractable timeline and resources

**For Production Silicon Verification (Post-Phase 9):**
- Use **Approach A** (Full SPICE) for critical corners only
- Example: 0.80V worst-case (ss, 125°C, min VDD)
- Run after Phase 9 GO to confirm no gate-level surprises
- Budget: 1-2 weeks compute time

5. ✓ `lock_valid` asserts with cal_done

**When all three pass:**
- `Synthesizable Startup Calibration Controller = GO`
