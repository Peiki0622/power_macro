# Phase 9 Corrected VCS-XA Acceptance

## Disposition

**Corrected three-voltage autonomous mixed-signal acceptance: GO.**

The historical `vcs_xa/` NO-GO evidence is preserved.  The corrected flow
confirms that the earlier failure was a mixed-signal harness non-equivalence:
the historical bench used a 10 ns physical clock and did not freeze the
electrical D2A/A2D boundary.  The frozen controller netlist and frozen sensor
netlist were not changed.

## Frozen inputs and tools

- Repository baseline recorded in `ROOT_CAUSE_BASELINE.json`; the current
  corrected-flow evidence was generated from the same synthesized-controller
  blob as the historical snapshot (SHA256 recorded in that file).
- Phase 1 contract: 1 GHz, 1 ns cycle; configuration settle is 2 cycles;
  S_CLK rise is cycle 1; Q samples are cycles 4 and 5; reset assertion is
  cycle 6; S_CLK fall is cycle 7; recovery completes at cycle 10.
- Mixed-signal pair: VCS P-2019.06-SP2 Full64 and PrimeSim XA S-2021.09-SP2.
- The XA deck uses the same frozen transistor sensor and standard-cell CDL for
  all three scenarios.  The only scenario input is `VDD_VALUE`.
- Autonomous transient budget is derived in `inputs/bridge_contract.json`:
  `45 * (2 + 11) + 20 + 100 = 705 ns` for the 0.80 V case.  The XA deck uses
  a 500 ps maximum transient step; the 1 ns digital contract is unchanged.

## Electrical boundary

- Sensor VDD/VSS are private SPICE nodes generated by
  `src/ftc_sensor_ams_wrapper.sp`; no VDD/VSS Verilog ports cross the generic
  interface boundary.
- Audited crossings are exactly one S_CLK, one reset, 16 medium rails, and 10
  fine rails.  The generated interface report contains 29 entries and no
  generic supply crossing.
- A2D `q_final` uses the normalized 0.30/0.70 VDD thresholds recorded in
  `inputs/bridge_contract.json`; the ambiguous region is not accepted.
