# B-FE7 W5 SCI Visualization

The atlas is rendered directly from the twelve manifest-hashed scenario CSV
files.  It uses a compact 4 x 3 layout, a common VDD axis, relative-to-`T_E`
time, a thin 1.10 V reference, and only the meaningful edge markers.  The
solid trace is always the actual noisy HSPICE input; no idealized trace was
manually redrawn.

The PDF is vector output and the PNG is 4320 x 4200 pixels at 600 dpi.  The
caption explicitly limits the figure to stimulus definitions and makes no
detector-performance claim.
